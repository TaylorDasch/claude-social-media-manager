## DESIGN NOTE — why this is a framework, not a tour

The viewer does NOT get walked house-to-house. They answer **one question — "what do you refuse to give up?"** — and that single answer sorts them into one of four buying lanes. Each neighborhood appears only as the **answer to a lane**, never as a destination. Every lane is presented with the **identical three numbers in the same order — price / square feet / dollars per square foot — held against the same ~$250,000 benchmark** so the trade is mathematically visible, not asserted. The spine is the Trade-Off Grid (one shared table the whole video returns to), and the payoff is a flowchart, not a ranking.

> Format keys: **[ON-SCREEN: …]** = lower-third / overlay text. **[B-ROLL: …]** = footage cue. **[BEAT @ x:xx]** = marked retention reset. **[GRID]** = the persistent Trade-Off Grid graphic, built one row at a time. Voice = data-first, honest, no hype. Talking-head to camera unless a cue says otherwise. Per §7, full-frame visuals reserved for maps and data cards; everything else stays lower-third overlay.
