# Mesa Ridge Production Checklist

## Before leaving for the open house

- [ ] Confirm the open-house time separately; do not trust the Matrix AM rendering.
- [ ] Charge camera, wireless audio, phone, gimbal, and optional drone batteries.
- [ ] Clear cards and set matching frame rates/white balance.
- [ ] Save this folder offline on the phone.
- [ ] Screenshot the hook, three signposts, recommend-against line, and CTA.
- [ ] If flying, use a current Part 107-certificated remote pilot with current recurrent training, or operate under that pilot's direct supervision; confirm registration/Remote ID, airspace, weather, launch permission, and any LAANC requirement. Otherwise, skip the drone.

## Before guests arrive or during the first quiet window

- [ ] Film the full hook twice.
- [ ] Film all 2032 interior and backyard proof before guest traffic.
- [ ] Record clean room tone and 15 seconds of exterior ambient sound.
- [ ] Avoid client paperwork, sign-in sheets, license plates, children, identifiable neighbors, seller/family photos, mail, medications, calendars, alarm/security screens, keys, and lockbox/access codes.
- [ ] Ask listing agent/owner before filming anything not already authorized for the listing.

## Neighborhood pickups

- [ ] Mesa Ridge/approach identifier without blocking traffic.
- [ ] One wide shot proving mixed home scale/rooflines.
- [ ] One safe public-right-of-way shot of one-story/two-story adjacency.
- [ ] One construction-versus-completed-street contrast if present today.
- [ ] SH 317 orientation shot.
- [ ] Optional Crossroads exterior/public-facility shot.
- [ ] No private-yard closeups or resident tracking.

## Required A-roll

- [ ] Hook with both medians and date context.
- [ ] 2032 price/property card line.
- [ ] Check 1 signpost.
- [ ] Product-comparison rule.
- [ ] Check 2 signpost.
- [ ] No-guaranteed-value/concession caveat.
- [ ] Check 3 signpost.
- [ ] On-site observation boundary.
- [ ] Recommend-against line.
- [ ] Full `MESA` CTA.

## Post-shoot verification

- [ ] Confirm every spoken number against `GROUND-TRUTH-2026-08-01.md`.
- [ ] Replace “today” with the exact date or remove it from volatile claims.
- [ ] Check that no school-quality, safety, resident-profile, or protected-class language slipped into riffs.
- [ ] Check that builder incentives are either omitted or independently verified and date-stamped.
- [ ] Use only one spoken CTA.
- [ ] Captions and description include the MLS-snapshot date.
- [ ] Thumbnail contains no more than four words.
- [ ] No publish, upload, embed, schema, email, or social action without Taylor's approval.
