**Publish #1** — leads the brand phrase, carries review intent, and matches the live page's defensible superlative ("most aggressive financing" = the PACKAGE: rate-or-$20K choice + USDA eligibility + $225,900 entry). Deliberately says "Financing," NOT "Fixed Rate" — D.R. Horton now advertises the same 4.99%, so the R2 title's rate superlative is falsifiable.

**Why no number in the title:** the 4.99% offer has a stated Aug-10 close-by date and Stylecraft's promos rotate roughly monthly. Titles are set ONCE (standing rule) — a rate in the title becomes a staleness trap the first time the promo rotates. Numbers live in the hook, thumbnail (swappable), and description (editable).

**Set-once discipline:** don't change the title before ~1,000 impressions — let it climb rank rather than chasing CTR early. If CTR still lags after 10–14 days, A/B swap to **#2** (the decision-shock number contrast) — but ONLY while the offer is verifiably live; #2 re-imports the staleness trap, so post-rotation it's off the table.
