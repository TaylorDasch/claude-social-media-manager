## 4. MAP ANIMATION SPEC — the weapon *(built: `map/belton-map-tour.html`)*

**Recommendation: build it as an HTML/CSS/SVG component you screen-record — NOT a baked After Effects graphic.** Three reasons: (1) you already work in scroll/animated map components (the homepage flyover), (2) it's **driveable to your voice** — you press space and the pin drops exactly when you say the name, which no pre-rendered graphic can do, and (3) it's **re-renderable**: when the MLS shifts next quarter you change the data array and the whole map updates — and the same file **embeds on the `/homes-for-sale-belton-tx` page** so the video and the page share one asset. It's already built and live in this folder.

### What it does (the sequence)
- **Opening flyover:** camera starts pulled-back and high, then eases down into the Belton frame (a real descending-camera feel via animated SVG `viewBox`), title card fades up: *"Every Neighborhood, Ranked by the MLS."*
- **Pin-drop sequence:** each `[SPACE]` drops the next ranked pin (stem grows, head pops with a spring, label slides in with name + price), the camera **flies to and zooms on** that pin, a full **data card** animates up bottom-left (rank, name, tagline, big median price, 4 stat tiles, one honest-note line), and the **leaderboard rail** on the right fills in that rung.
- **Color-coded price bands:** pins ramp **teal (entry) → green → gold → orange → red (top)** so the climb is visible at a glance.
- **Split lake tier:** stop #8 drops **two** markers (Belton Lake + Stillhouse Hollow) and the camera pulls wide to frame both — the geographic nuance Aundrea flattens.
- **Tax pit stop:** a full-screen overlay — *"Same $300K home, three different tax bills"* — in/edge/out cards, with the bellcad.org verify line.
- **Off-list finale:** a **ghost/dashed violet pin** drops on Sage Meadows over on the Temple side — visually set apart from the 8 ranked Belton pins.
- **Outro:** camera pulls wide, every pin lit, the full ladder fills, CTA card: *Text BELTON to 254-718-4249.*

### How you drive it (recording controls)
| Key | Action |
|---|---|
| **`Space` / `→`** | Next step (drop next pin / advance) — your main VO-sync key |
| **`←`** | Back one step |
| **`1`–`8`** | Jump straight to that ranked pin (for pickups) |
| **`9`** | Tax pit stop · **`0`** outro |
| **`R`** | Reset to the intro |
| **`C`** | **Hide all chrome** (HUD + progress bar) for a clean recording |
| Click left third / right | Back / forward (mouse alternative) |

**Recording workflow:** open in Chrome fullscreen → press **`C`** to hide chrome → start your screen recorder at the rendered 16:9 frame → read the script, pressing **`Space`** on each neighborhood name. The map is letterboxed to a clean 16:9 so the capture is broadcast-ready.

- **Palette:** deep navy field (`#04070f → #0a1628`), ember/amber accent (`#f59e0b / #fbbf24`) for active pin + CTA, slate body text `#e2e8f0` (your locked body-text standard), water in teal (`#0c2f3d` w/ `#1d6b84` shoreline), violet (`#a78bfa`) reserved for the off-list pin.
