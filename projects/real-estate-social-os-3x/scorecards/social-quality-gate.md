# Social Quality Gate

Use this before any social packet is shown as ready for Taylor review.

## Score

| Dimension | Points | Pass bar | Notes |
| --- | ---: | --- | --- |
| Source proof | 15 | All claims sourced and dated. |  |
| Platform fit | 15 | Native to the platform, not copy-paste. |  |
| Hook strength | 10 | Specific, clear, and audience-aware. |  |
| Audience lane | 15 | No buyer/investor or channel mixing. |  |
| Lead path | 15 | CTA, lead magnet, UTM, source note. |  |
| SEO/GEO/AEO value | 10 | Supports page, entity, GBP, review, or video bridge. |  |
| Registry/dedupe | 10 | Parent, status, overlap, next state known. |  |
| Approval safety | 10 | Draft-only, no live action. |  |

Pass bar: 85/100 and zero hard blockers.

## Hard Blockers

- Unsourced number or market claim.
- Investor TikTok.
- Raw private MLS details in public copy.
- Mixed Living in Temple and Investing in Temple audience.
- Missing CTA or lead path.
- Live action without approval.
- Claim about rates, incentives, rankings, or performance without current proof.
